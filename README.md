# Work API

Projeto focado na implementação e consumo de APIs em ambiente Android, explorando chamadas assíncronas e processamento em segundo plano.

## Conteúdo
- Gerenciamento de tarefas de rede.
- Exemplos de integração com serviços externos.

## Tecnologias
- Android SDK
- Retrofit / Volley (provavelmente)
- WorkManager
